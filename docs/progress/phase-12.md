# 阶段 12：人工质检闭环与无障碍加固

日期：2026-08-27
状态：工程完成，等待集中人工验收

## 本阶段交付

- 对冻结的 7 例真实换脸结果重新复核，确认自动身份、关键点、背景和色差指标仍无法可靠识别两类明显伪影。
- 为结果区新增“放大质检”入口，在完整且不裁切的深色弹窗中检查结果，并可在新窗口查看原始分辨率。
- 在界面中明确列出双眼、牙齿与嘴唇、发际线、脸部轮廓和肤色接缝五类人工检查点。
- 对小于 96 像素、超近景或贴近画面边缘的所选人脸显示保守风险提示；提示不阻断任务，也不被表述为质量评分。
- 为主结果质检弹窗和本地图库弹窗补齐 Esc 关闭、Tab 焦点循环、关闭后焦点回到触发按钮和背景滚动锁定。
- 复核 Dependabot 前端安全更新组与 Python 更新组。前端组为开发工具常规 minor/patch 更新；Python 组会把 ONNX Runtime 与 CUDA 运行时跨代升级至 CUDA 13 体系。候选版冻结期间两组均不自动合并，尤其不得把未做真实 GPU 回归的 CUDA 跨代更新混入发布分支。

## 质量判断边界

本阶段解决的是“用户能否真正执行人工检查”和“已知高风险几何条件是否得到提醒”，不是传统 128 像素模型的固有质量上限。复杂妆容、纹理破碎和部分错位仍不能由现有五点人脸坐标或聚合指标可靠自动判定。任何结果在下载或公开使用前仍需人工检查。
