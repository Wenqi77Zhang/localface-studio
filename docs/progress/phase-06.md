# 阶段 6：质量、性能与稳定性评测

日期：2026-08-26  
状态：完成

## 本阶段交付

- 建立本地授权样例清单驱动的可重复批量评测脚本。
- 对 Identity 与 Balanced 两个质量预设完成 7 组、14 次 CUDA 真实换脸。
- 记录身份余弦相似度、关键点 NRMSE、脸外变化率、核心 LAB 色差、尺寸与耗时。
- 增加纯指标函数的单元测试，并建立独立人工盲评模板。
- 在结果预览中增加明确的人工伪影检查提示。
- 公开仓库仅提交方法与聚合结论，不提交人物图片、生成结果或逐图明细。

## 验证结论

- Balanced 预设在冻结样例上满足身份非劣条件，并略微改善色彩衔接，因此继续作为默认值。
- 热任务 P95 为 5.181 秒；冷启动模型加载为 61.261 秒。
- 人工复核发现 2/7 个明显不可接受结果，证明自动指标不能替代视觉验收。

详细数据和限制见[真实换脸质量基线](../benchmarking/FACE_SWAP_QUALITY_BASELINE.md)。
