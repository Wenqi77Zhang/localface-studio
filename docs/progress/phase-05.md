# 阶段 5：质量优化

状态：工程实现完成，纳入阶段 6 多样本评测
完成日期：2026-08-26

## 设计原则

- InSwapper 自带的对齐、差异遮罩与羽化融合继续作为“身份优先”基线，不重复实现未经验证的整脸粘贴。
- 新增优化只能作用于已选目标人脸的有界区域，遮罩外像素必须保持不变。
- 不引入尚未完成代码、权重和训练数据三层许可证审核的人脸增强模型。
- 每个预设写入任务数据库和导出元数据，结果可以追溯，不允许隐藏后处理。

## 已完成

- 新增 `identity` 与 `balanced` 两个稳定质量预设。
- `identity` 保留 InSwapper 官方融合结果，不增加颜色修正。
- `balanced` 在目标脸框内生成椭圆羽化遮罩，以 LAB 色彩空间的稳健中位数估计目标与换脸结果的颜色偏移。
- 颜色偏移限制为 L 通道最多 10、a/b 通道最多 6，再以 0.35 强度渐进应用，减少过度校色。
- 遮罩边缘使用与脸尺寸相关的高斯羽化；遮罩权重低于 0.001 的区域直接复制原换脸结果，保证远离目标脸的像素完全不变。
- 高级设置新增“质量预设”；`balanced` 作为当前推荐值，用户可随时切回 `identity` 原始融合。
- 质量预设贯穿前端请求、后端枚举、SQLite 迁移、任务读取、原生执行和导出元数据；非法字符串由 API 拒绝。
- 模拟回归结果也记录预设，但不执行真实质量处理，避免测试路径丢失契约字段。
- 新增本地消融脚本，只输出到 Git 忽略目录；报告明确说明颜色距离不能替代身份指标。

## 单例实现消融

使用阶段 4 同一已授权本地研究样例，对原始融合结果再执行 `balanced`：

| 指标 | identity | balanced |
|---|---:|---:|
| 目标脸核心区 LAB 平均绝对误差 | 5.505960 | 5.275816 |

其他约束：

- `balanced` 相对 `identity` 的核心区 BGR 平均变化为 1.760707。
- 任意通道最大绝对变化为 8。
- 羽化遮罩外改变像素数为 0。
- 人工查看未发现背景、身体、钢琴或融合边界异常。
- 完整产品 API 使用 `balanced` 再次执行成功，最终实际执行器为 CUDA。

## 结论边界

该消融证明当前实现能够在一个样例上小幅降低目标颜色差异，并严格保持遮罩外不变；它不能证明身份更相似、所有肤色均受益或真实世界质量普遍提高。阶段 6 将使用 ArcFace 对齐后余弦相似度、区域外变化、关键点与多样本统计复核默认值。如果身份指标下降或多样本颜色收益不稳定，默认值必须回退到 `identity`。

人脸增强模型继续保持未选型状态。零付费不等于许可安全；没有完整权利链和独立消融证据时，不加入默认产品。
