# 阶段 3：人脸检测与目标选择

状态：进行中  
开始日期：2026-07-24

## 已确认范围

- 默认检测器为 OpenCV YuNet，最终冻结前先完成本机兼容性与困难场景验证。
- 高级设置预留人脸检测模型选择。
- 支持 `yunet-opencv`、仅限本地非商业研究的 `scrfd-insightface-research`，并为未来 `scrfd-custom` 预留接口。
- 切换检测器后，检测框、稳定编号和人物选择全部失效并重新检测。
- 官方 InsightFace SCRFD 权重不得提交、镜像或随安装包分发。
- 商业模式由后端禁止加载研究权重。

## 当前完成

- 已比较 YuNet、SCRFD、RetinaFace 和 MediaPipe/BlazeFace 的工程适用性。
- 已确认检测模型与换脸模型的职责边界。
- 已冻结可替换检测器和许可证隔离架构，见 `docs/architecture/ADR-003-face-detector-profiles.md`。
- 已在 Python 3.14.6 中验证 opencv-python-headless 5.0.0.93、NumPy 2.5.1 和 `FaceDetectorYN` 可用。
- 已从 OpenCV 官方仓库取得 `face_detection_yunet_2026may.onnx`，验证大小为 229738 字节，SHA-256 为 `ebafce4e3c118d6554634be5c27ab333b4c047a9a8c3faf1d7cf93101c22f0f0`。
- 已完成模型加载及程序生成无脸图的 CPU 推理检查，正确返回零张人脸。
- 已建立可提交的 `config/models.json`；权重文件仍位于 Git 忽略目录。
- 已实现统一 `FaceDetector` 协议，以及不含图片、路径和身份向量的检测结果领域模型。
- 已实现 `YuNetFaceDetector`：加载前校验模型角色、大小和 SHA-256，并支持商业模式许可证门禁。
- 检测结果包含原图坐标边界框、五点关键点、置信度和由模型身份与几何信息生成的稳定检测 ID，不依赖模型返回数组下标。
- 多脸结果按从上到下、从左到右的几何顺序展示；重复稳定 ID 只保留最高置信度结果。
- 超大图片在内存中按最长边 1920 像素等比例缩放检测，输出坐标映射回原图；不持久化缩放图或检测缓存。
- 新增模型清单、领域对象和 YuNet 适配器测试；关键新增模块针对性覆盖率达到 85% 以上。
- 已新增上传即检测 API：单脸自动选中，多脸必须显式选择，无脸返回空结果供界面明确提示。
- 检测修订按浏览器会话与图片角色隔离；重新上传或切换模型开始时，旧修订立即失效。
- 检测上传使用一次性随机工作区，推理完成或失败后均删除图片；内存中仅保留最多 30 分钟的检测坐标、模型身份和不可逆内容摘要。
- 检测修订总量设为 256 条上限，服务重启后全部失效，防止内存无界增长。
- 选择接口校验检测 ID 必须属于同一修订；跨会话读取和选择统一返回不存在，避免泄露记录。
- 本小步完整后端质量门通过：82 项测试，总覆盖率 88.61%，公开仓库扫描通过。
- 前端已在图片选定后自动调用本地检测 API，并对检测中、失败、无脸、多脸待选择和已选择状态给出组件内提示。
- 检测框按 `object-fit: contain` 的实际图像显示区域映射原图坐标，兼容横图、竖图、共享预览框和黑边。
- 单脸在界面中自动选中；多脸使用稳定编号，用户每侧必须且只能选择一人。
- 未检测到人脸、检测失败或多人尚未选择时，前端拒绝提交处理任务并给出缺失项指引。
- 高级设置已展示 YuNet 默认项，并诚实标注尚未安装的 InsightFace SCRFD 和未来自训练 SCRFD 预留项；不可用项不能选择。
- 已人工验收单脸、多脸、无脸、重新上传和移除五个场景；完整质量门通过 83 项测试，总覆盖率 88.66%。
- 任务创建现在必须同时提交两侧检测修订 ID 和所选人物 ID；缺失字段不能绕过界面直接创建任务。
- 后端在隔离工作区保存任务图片后重新计算文件 SHA-256，并与当前会话的检测修订比对；图片字节变化、修订过期、角色错配、跨会话引用或人物 ID 错配均拒绝创建并清理工作区。
- 任务数据库仅新增检测器 ID 和两侧所选人物 ID；修订 ID、图片摘要、检测框、关键点和身份向量不写入任务数据库。
- 旧 SQLite 数据库启动时自动增加可空字段，既有阶段 2 任务继续可读；阶段 3 新任务必须写入完整选择元数据。
- 已人工验收单脸正常提交与多人选择人物 2 后提交；只读核验确认最新任务保存 `yunet-opencv` 和两侧人物 ID。
- 本小步后端与前端检查通过：85 项测试，总覆盖率 88.85%，公开仓库扫描和生产构建通过。
- 已修复 JPEG EXIF 方向未应用的问题：产品检测与基准脚本共用自动转正解码器，API 宽高改用转正后的实际检测尺寸，避免浏览器预览与检测框坐标错位。
- 已增加 EXIF 旋转与普通图片回归测试；完整后端质量门通过 100 项测试，总覆盖率 87.29%，公开仓库扫描和健康检查通过。
- 已冻结 `real20-v1` 本地真实图片检测基准：20 张逐图审核的 CC BY 2.0 图片、30 张人工复核人脸；原图、逐图台账、人工框和逐图报告继续由 Git 隔离。
- 已完成 YuNet 同参数评测：18 个真阳性、0 个误检、12 个漏检，召回率 60.00%，精确率 100.00%；该结果只适用于当前小型困难样本集。
- 已新增可公开审查的脱敏冻结摘要，记录准入门禁、评测配置、类别切片、结论边界和版本变更规则。
- YuNet 保留为零付费、CPU 优先且许可证边界较清晰的临时默认检测器；因困难场景漏检明显，最终模型选择仍等待 SCRFD 同条件对比。
- 已加入不含模型权重的 `ScrfdResearchFaceDetector` 公开适配器骨架，按官方当前接口支持 128×128 与 640×640 双尺寸检测、CPU 执行、边界框和五点关键点映射。
- SCRFD 研究适配器只有在显式确认研究用途限制、模型清单角色正确且本地文件大小和 SHA-256 均匹配后才能创建；商业模式始终拒绝加载官方研究权重。
- SCRFD 网页启用状态仍未改变，不能从网页选择；应用运行时不会自动联网下载任何模型资产。
- 新增 SCRFD 输出映射、去重排序、异常输出、运行失败、许可证确认、商业模式拒绝、缺失或篡改权重测试；YuNet 与 SCRFD 共用严格图片输入校验。
- 已将 InsightFace 1.0.1 与 ONNX Runtime 1.29.0 锁定为 `scrfd-research` 可选依赖；默认项目安装不会启用这套研究运行库。
- 已在 Python 3.14.6、Windows 环境验证 InsightFace、适配器和 ONNX Runtime CPU Provider 可导入。为避免两个 OpenCV 发行包共享 `cv2` 文件，uv 排除 InsightFace 的普通 `opencv-python` 传递依赖，并继续使用 `opencv-python-headless` 5.0.0.93。
