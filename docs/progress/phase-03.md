# 阶段 3：人脸检测与目标选择

状态：进行中  
开始日期：2026-07-24

## 已确认范围

- 默认检测器为 OpenCV YuNet，最终冻结前先完成本机兼容性与困难场景验证。
- 高级设置预留人脸检测模型选择。
- 支持 `yunet-opencv`、仅限本地非商业研究的 `scrfd-insightface-research`，并为未来 `scrfd-custom` 预留接口。
- 切换检测器后，检测框、稳定编号和人物选择全部失效并重新检测。
- 官方 InsightFace SCRFD 权重不得提交、镜像或随安装包分发。
- 商业模式由后端禁止加载研究权重。

## 当前完成

- 已比较 YuNet、SCRFD、RetinaFace 和 MediaPipe/BlazeFace 的工程适用性。
- 已确认检测模型与换脸模型的职责边界。
- 已冻结可替换检测器和许可证隔离架构，见 `docs/architecture/ADR-003-face-detector-profiles.md`。
- 已在 Python 3.14.6 中验证 opencv-python-headless 5.0.0.93、NumPy 2.5.1 和 `FaceDetectorYN` 可用。
- 已从 OpenCV 官方仓库取得 `face_detection_yunet_2026may.onnx`，验证大小为 229738 字节，SHA-256 为 `ebafce4e3c118d6554634be5c27ab333b4c047a9a8c3faf1d7cf93101c22f0f0`。
- 已完成模型加载及程序生成无脸图的 CPU 推理检查，正确返回零张人脸。
- 已建立可提交的 `config/models.json`；权重文件仍位于 Git 忽略目录。
- 已实现统一 `FaceDetector` 协议，以及不含图片、路径和身份向量的检测结果领域模型。
- 已实现 `YuNetFaceDetector`：加载前校验模型角色、大小和 SHA-256，并支持商业模式许可证门禁。
- 检测结果包含原图坐标边界框、五点关键点、置信度和由模型身份与几何信息生成的稳定检测 ID，不依赖模型返回数组下标。
- 多脸结果按从上到下、从左到右的几何顺序展示；重复稳定 ID 只保留最高置信度结果。
- 超大图片在内存中按最长边 1920 像素等比例缩放检测，输出坐标映射回原图；不持久化缩放图或检测缓存。
- 新增模型清单、领域对象和 YuNet 适配器测试；关键新增模块针对性覆盖率达到 85% 以上。
- 已新增上传即检测 API：单脸自动选中，多脸必须显式选择，无脸返回空结果供界面明确提示。
- 检测修订按浏览器会话与图片角色隔离；重新上传或切换模型开始时，旧修订立即失效。
- 检测上传使用一次性随机工作区，推理完成或失败后均删除图片；内存中仅保留最多 30 分钟的检测坐标、模型身份和不可逆内容摘要。
- 检测修订总量设为 256 条上限，服务重启后全部失效，防止内存无界增长。
- 选择接口校验检测 ID 必须属于同一修订；跨会话读取和选择统一返回不存在，避免泄露记录。
- 本小步完整后端质量门通过：82 项测试，总覆盖率 88.61%，公开仓库扫描通过。

## 下一小步

1. 在前端图片预览上接入上传即检测，展示检测框、稳定编号和单目标选择。
2. 将来源图与目标图的检测修订、所选检测 ID 接入任务创建校验，拒绝图片、模型或选择已过期的请求。
3. 使用不含个人或未授权人脸的许可测试素材验证单脸、多脸、无脸、小脸、遮挡和旋转行为。
