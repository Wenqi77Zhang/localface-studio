# Windows 可复现性实测报告

日期：2026-08-26  
目标：验证锁定环境、启动链和诊断链不依赖项目外 Python 包或 Node 模块

## 已验证环境

- 64 位 Windows
- Python 3.14.6
- 项目内 `.venv`
- Node.js 24.18.0 项目内便携运行时
- RTX 5060 Laptop GPU；ONNX Runtime 同时识别 CUDA 与 CPU Provider

## 已执行检查

1. `scripts/bootstrap.ps1 -Offline` 成功按 `uv.lock` 重建项目包，并从项目缓存严格安装全部前端依赖；审计报告为 0 个已知漏洞。
2. 前端严格按锁文件构建通过。
3. 中文诊断脚本正确识别 Python、Node、前端依赖和端口；四个本地模型的完整 SHA-256 全部匹配，CUDA/CPU Provider 同时可用。
4. 统一质量门完成 Python 静态检查、严格类型检查、139 项测试、82.36% 覆盖率、当前文件与完整 Git 历史扫描、后端启动、前端生产构建和真实代理演练。
5. 原生真实 API 与 CUDA 换脸路径已在阶段 4 演练；阶段 6 完成 7 组、14 次真实换脸质量与性能基线。

## 不能从当前电脑证明的事项

- 尚未在另一台完全干净的 Windows 物理机上由独立用户逐步复现。
- 受限研究模型必须人工接受许可证并从官方来源取得，不能自动纳入安装包。
- GPU 驱动、CUDA 运行库和厂商硬件差异仍可能导致目标机降级到 CPU。
- 可选 ComfyUI 适配器使用协议替身完成自动测试，但未捆绑或认证任何第三方真人换脸工作流。

因此，本报告证明当前目标机上的锁定重建与端到端链路，不把它夸大为跨设备安装已经验收。最终发布前仍需按[用户手册](USER_GUIDE.md)在一台干净 Windows 设备进行独立复现，并记录设备、驱动、耗时和失败修复。
