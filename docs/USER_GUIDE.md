# LocalFace Studio 用户手册

适用版本：单张照片研究版 v1 候选  
支持系统：64 位 Windows 10/11  
费用：应用本身与默认本地运行严格零付费

## 1. 使用前须知

- 只处理已取得合法授权的成年人影像。
- 当前 InSwapper、ArcFace 和可选 SCRFD 预训练权重仅限个人学习和非商业研究，不能直接用于公开商业服务。
- 图片与结果默认只在本机处理。成功后两张上传原图会立即从服务端工作区删除，只按所选期限保留处理结果。
- 可见 AI 水印默认开启；即使关闭，AI 编辑元数据仍会写入文件。
- 传统 128 像素换脸模型可能产生眼睛、牙齿、发际线或轮廓伪影，下载前必须放大检查。

## 2. 首次安装

先安装两个免费前置工具：

1. [Python 3.14 64 位](https://www.python.org/downloads/windows/)，安装时保留 Python Launcher。
2. [uv 官方安装说明](https://docs.astral.sh/uv/getting-started/installation/)。

然后在项目根目录双击 `setup.cmd`。脚本会：

- 在项目内部创建 `.venv`，不会污染其他 Python 项目；
- 严格按 `uv.lock` 安装 Python 依赖；
- 下载固定版本的官方 Node.js 便携包，并同时核对官方清单和项目冻结 SHA-256；
- 严格按前端锁文件安装依赖。

模型不会自动下载或进入 GitHub。只有接受非商业研究限制后，才按[本地开发指南](DEVELOPMENT.md#单独安装研究模型)取得 YuNet、InSwapper 与 ArcFace 文件；SCRFD 是可选研究检测器。

## 3. 安装诊断

在项目文件夹空白处按住 Shift 单击右键，选择“在终端中打开”，执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\diagnose.ps1
```

诊断只检查程序、端口、模型大小和推理执行器，不读取图片或身份信息。需要完整核验模型哈希时执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\diagnose.ps1 -FullModelHash
```

`OK` 表示通过，`WARN` 表示仍可继续但需要留意，`FAIL` 必须先修复。端口 8000 或 5173 被占用通常表示旧的 LocalFace Studio 仍在运行，关闭旧终端后重试。

## 4. 启动与关闭

双击 `start.cmd`。准备完成后默认浏览器会打开：

<http://127.0.0.1:5173/>

必须使用这个地址；不要改成 `localhost`、局域网 IP 或其他端口。关闭时回到启动窗口按 `Ctrl+C`，脚本会同时停止前端和后端。只关闭浏览器标签页不会停止本地服务。

## 5. 完成一次换脸

1. 上传“身份来源图”。优先选择单人、正脸、清晰、无遮挡的成年人照片。
2. 上传“目标场景图”。检测到多张脸时，点击且只选择一个待替换人物。
3. 检查检测框确实对应正确人物。
4. 勾选影像授权与合法用途确认。
5. 阅读并勾选非商业研究模型限制。
6. 如无特殊需求，保持 YuNet、平衡优化、PNG、30 分钟和 AI 水印默认值。
7. 点击“开始本地换脸”，等待节点流程进入完成状态。
8. 拖动前后对比线并放大检查眼睛、牙齿、发际线、脸部轮廓和未选择人物。
9. 通过后下载结果；不满意时更换更清晰、角度更接近的来源图重试。

按钮在资料不完整时仍可点击，但只会标出缺少的图片、选择或确认，不会偷偷开始处理。

## 6. 高级设置

- **人脸检测模型**：YuNet 许可证边界更适合公开代码；SCRFD 在本地基准召回更高，但预训练权重仅限非商业研究。
- **质量预设**：平衡优化在身份非劣前提下做轻量颜色协调；身份优先保留原始融合。
- **输出格式**：PNG 保留无损像素；JPEG 文件更小，可选 5–100 质量，95 为默认值。
- **本地保留**：30 分钟、1、3、6、12 或 24 小时；24 小时是硬上限。
- **AI 水印**：默认开启。关闭时会二次确认，但不能关闭文件内的 AI 编辑元数据。

## 7. 本地结果图库与删除

左侧图库只显示当前匿名浏览器会话中未过期的处理结果，按生成时间从新到旧排列。匿名会话最长 24 小时，并会随正常使用续期，因此同一浏览器在后端重启后仍可找回保留期内结果；清除浏览器 Cookie、换用其他浏览器或会话过期后无法再访问旧会话结果。点击缩略图可查看完整大图、下载或清除此结果；也可以一次清除全部结果。

“清除此结果”会删除应用工作区中的结果，不会删除已经下载到 Windows“下载”文件夹或用户另存的位置。若不主动删除，结果会在所选保留期结束后自动清理。普通删除不是取证级安全擦除。

## 8. 常见问题

### 页面显示 `request origin is not allowed`

确认地址栏是 `http://127.0.0.1:5173/`，并通过 `start.cmd` 启动。不要直接双击前端 HTML，也不要使用浏览器代理改写地址。

### 页面显示模型缺失

运行诊断并按模型清单放到准确的相对目录。文件名正确但大小或 SHA-256 不匹配时必须重新从官方来源取得，不能绕过校验。

### 只有 CPU，没有 CUDA

程序会明确降级到 CPU，不会伪装成 GPU。先更新 NVIDIA 驱动并重新运行 `setup.cmd`；仍失败时以诊断结果为准。CPU 会明显更慢。

### 一直检测不到脸

换用更清晰、更正面、占画面更大的成年人照片。YuNet 在冻结小样本中对大脸贴边、侧脸、遮挡和帽檐存在明显漏检；非商业研究条件允许时可比较 SCRFD。

### 结果有重影或轮廓破碎

这是当前传统模型的已知上限，不是浏览器显示问题。更换角度和光照更接近的来源图；若仍明显，不要公开使用该结果。

### `Ctrl+C` 后仍无法访问或端口仍占用

等待数秒再运行诊断。若端口仍为 WARN，关闭残留的启动终端；不要盲目结束未知系统进程。

## 9. 更新与回滚

更新前先清除或下载需要保留的结果，然后在仓库根目录执行：

```powershell
git pull --ff-only origin main
.\setup.cmd
```

`--ff-only` 会在本地存在分叉时停止，避免静默覆盖修改。回滚应使用 Git 创建新分支或切换到已知标签；不要使用 `git reset --hard` 处理含个人改动的工作区。

## 10. 卸载

先停止应用并清除图库，再删除整个项目文件夹即可。项目环境、Node.js、缓存和运行结果都位于项目内部。已经下载到其他目录的图片需要由用户自行删除。
