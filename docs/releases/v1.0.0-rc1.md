# LocalFace Studio v1.0.0-rc1

这是供最终集中验收的单张照片本地换脸候选版，不是商业版本，也不是稳定 `v1.0.0`。

## 主要能力

- 本地 Web 产品，来源图与目标图上传，多脸检测后每次只替换一个选中人物。
- YuNet 默认检测，SCRFD 作为明确门禁的非商业研究对比。
- GPU 优先的 ArcFace + InSwapper 原生研究后端，GPU 失败时显式重建 CPU 会话。
- 身份优先与平衡颜色协调预设，PNG/JPEG、水印、永久 AI 元数据和最长 24 小时结果保留。
- 成功后立即删除上传原图；图库支持查看、下载、单项清除和全部清除。
- 默认关闭的进程外 ComfyUI 适配器，不附带第三方节点、工作流或模型。
- Windows 双击初始化/启动、中文诊断、用户手册、公开仓库扫描和 GitHub Actions。

## 已知限制

- 真实 7 例基线中有 2 例出现明显重影或融合伪影；自动身份与几何指标未能可靠识别，因此所有结果必须人工放大检查。
- 当前研究权重不能直接用于商业服务。
- 独立干净 Windows 物理机复现和产品负责人最终视觉验收仍待完成。
- 视频只冻结 v2 接口，v1 不支持视频上传或处理。
- ComfyUI 协议适配已测试，但仓库未认证任何具体第三方真人换脸工作流。

## 隐私提醒

不要在 GitHub Issue、Pull Request 或公开演示中上传私人脸图、生成结果、模型、身份向量、运行数据库、凭据、完整路径或未脱敏日志。
