# v1.0.0-rc3：真实双模型与配对结果

日期：2026-09-11。仅限本地单用户、单张照片、非商业研究；本轮不部署。

## 本次变化

- 可选 AlphaFace 256（2026），默认保留 InSwapper 128；检测器独立选择 YuNet/SCRFD，未安装模型禁选。
- 独立 `FaceSwapper` / `FaceEnhancer` 边界，基础/优化结果分开保存、比较、下载；优化是局部颜色校正，不是五官恢复或超分辨率。
- 默认真实后端，模拟需要显式设置且披露；完全不变或尺寸不合法的输出拒绝发布。
- 小缩略图、到期访问拒绝、浏览器预览撤销、成组删除及占用失败重试。
- 有界事件缓存、切换模型释放会话、局部区域处理与真实 RSS/整设备显存采样；冷加载不阻塞能力接口。

## 更新

停止旧启动窗口、保留个人改动，在仓库根目录执行 `git pull --ff-only origin main`，运行 `setup.cmd`，再运行 `diagnose.cmd` 与 `start.cmd`。只更新源码不重建前端会看到旧页面。

AlphaFace 是额外可选文件；未下载不影响原有 InSwapper 使用。安装位置和摘要见[开发指南](../DEVELOPMENT.md)。没有破坏性数据库迁移，旧结果在有效期内兼容读取。

真实 7×2 模型任务和 20 次连续测试见[实测报告](../benchmarking/MODEL_MATRIX_2026_09.md)，浏览器和工程检查见[阶段 16](../progress/phase-16.md)。AlphaFace 并未全面胜出，困难图片仍可能伪影。

不创建稳定版标签：负责人视觉验收、独立干净 Windows 复现和更广泛持续负载仍未完成。当前权重不能商用；账号、视频、公网没有实现，不虚报交付。
