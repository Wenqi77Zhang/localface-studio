# LocalFace Studio v1.0.0-rc2

这是在 rc1 基础上的成熟度与安全加固候选版，仍不是商业版本或稳定 `v1.0.0`。

## 相比 rc1 的变化

- 同一浏览器在后端重启后仍可访问保留期内结果；匿名会话最多 24 小时并随正常使用续期。
- 本地数据库只保存 Cookie 的 SHA-256 摘要，不保存原始 Cookie。
- 顶部状态能区分真实换脸可用、GPU/CPU、仅模拟和配置缺失，并在任务后刷新。
- 增加 Dependabot、CodeQL、成熟度审计和公网生产门禁。

## 保持不变的限制

- 当前研究模型不能用于公开商业服务。
- 真实基线仍存在无法由自动指标可靠拦截的明显伪影。
- 视频、账户和公网多租户能力仍未实现。
- 稳定标签仍等待产品负责人视觉验收和独立干净 Windows 复现。
