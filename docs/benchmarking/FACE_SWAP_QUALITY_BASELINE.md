# 真实换脸质量基线 v1

日期：2026-08-26  
状态：阶段 6 自动评测完成；独立盲评模板已建立

## 范围与数据边界

- 使用 7 个本地保存、已核验授权且仅含成年人的目标样例。
- 每个目标分别运行 `identity` 与 `balanced` 两种质量预设，共完成 14 次换脸。
- 测试原图、逐图结果和明细 JSON 均由 Git 隔离；公开仓库只保留聚合结果和评测方法。
- 测试使用同一身份来源图，因此本结果适合比较两个预设，不代表所有身份、肤色、姿态和光照条件。

## 性能基线

- CUDA 冷启动：61.261 秒。
- CUDA 热任务中位数：2.042 秒。
- CUDA 热任务 P95：5.181 秒。
- 14 个结果均保持目标图原始尺寸。

冷启动包含模型加载和首次 CUDA 初始化，不能与后续热任务直接比较。

## 人工视觉复核

7 个 Balanced 结果中有 2 个出现明显不可接受的视觉伪影：一个是眼部重影，另一个是
脸部融合边界和局部纹理破碎。另有个别大角度或复杂妆容样例自然度一般。这些失败并未被
身份相似度、关键点误差或脸外变化率可靠识别。

因此，当前自动指标只能验证身份趋势、几何位置和背景保护，**不能证明结果美观或无伪影**。
产品在结果区域明确要求用户下载前放大检查眼睛、牙齿、发际线和脸部轮廓。正式对外发布前，
还应使用[盲评模板](FACE_SWAP_BLIND_REVIEW_TEMPLATE.md)进行独立人工评分。

## 结论

阶段 6 的结论不是“质量问题已经解决”，而是建立了可重复的真实基线并暴露出传统 128 像素
换脸模型在复杂样例上的上限。默认 Balanced 预设可以保留，但输出仍须逐张人工验收；未来模型
替换必须在同一冻结样例集上复跑，并同时比较身份、伪影、背景保护和性能。
