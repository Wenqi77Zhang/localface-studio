# 人脸检测两层基准

状态：已冻结，公开合成样例完成 12/12  
冻结日期：2026-07-28

## 目标

本基准只评价“图片中是否正确找到人脸框”，不进行身份识别、身份相似度、人口属性推断或人物排名。

## 第一层：公开安全合成基准

- 计划包含 12 张为本项目生成的合成人物图片。
- 图片、生成说明、人工复核框和评测结果可以进入公开 GitHub 仓库。
- 场景覆盖单脸、多脸、小脸、部分遮挡、侧脸、旋转、逆光和低照度。
- 合成结果只能用于工程回归，不得声称代表真实世界人口分布或正式学术数据集。

## 第二层：本地真实图片基准

- 计划从 Open Images V7 候选集中筛选 20 张图片。
- 每张图片必须逐一核验作者、原始链接、明确许可证、下载日期和 SHA-256。
- 原图、检测输出和任何可识别人物裁剪不得提交 GitHub。
- 公开仓库最多保存不含私人路径的汇总指标与许可证审查结论。
- Open Images 对图片许可不作保证；无法完成逐图核验的候选必须剔除。

## 暂不采用的数据集

- WIDER FACE：仅引用 OpenCV 官方公布的外部指标；在取得明确的再分发和使用许可证据前，不下载、不提交，也不用于商业训练。
- InsightFace 研究数据集：不得进入商业模式、安装包或公开测试资产。

## 指标

- IoU 阈值：0.5。
- 真阳性：一个检测框与一个人工复核框达到阈值，且两者均只匹配一次。
- 召回率：成功匹配的人脸数除以人工复核人脸数。
- 精确率：成功匹配的人脸数除以检测框总数。
- 同时记录误检数、漏检数、单图推理耗时和失败类别。

## 结论边界

第一轮结果只能回答“当前 YuNet 配置是否足以进入下一阶段”，不能证明模型适合所有人群、环境或商业部署。正式公开使用前仍需扩大真实授权样本并进行公平性、隐私和安全复核。

## 公开合成基准结果

评测日期：2026-07-29  
运行环境：Windows、AMD64、Python 3.14.6、OpenCV 5.0.0  
模型与配置：项目模型清单校验通过的 `yunet-opencv`，IoU 阈值 0.5

| 指标 | 结果 |
| --- | ---: |
| 合成图片 | 12 |
| 人工标注人脸 | 16 |
| 检测框 | 13 |
| 真阳性 | 13 |
| 误检 | 0 |
| 漏检 | 3 |
| 召回率 | 81.25% |
| 精确率 | 100% |

本轮漏检发生在以下三个有意设置的困难场景：

- 约 24×32 像素的远景单脸；
- 约 40 度的平面内旋转；
- 贴近画面边缘且被部分裁切的脸。

同一基准中的混合尺度多人图包含约 23×30 像素的远处人脸，YuNet 成功检出。这说明人脸像素尺寸不是唯一变量，清晰度、背景、姿态和上下文也会影响结果，不能从单个样例推导固定的最小检测尺寸。

## 阶段决策

结论：**有条件进入下一阶段。**

YuNet 当前可以继续作为零付费、CPU 优先、许可证边界较清晰的默认检测器，用于标准正面、多脸、逆光、低照、运动模糊、常见透明眼镜和部分侧脸场景。本轮没有观察到误检。

以下限制必须继续保留：

- 不将 12 张合成图的结果宣传为真实世界准确率、人口公平性结论或商业可靠性证明；
- 产品界面继续允许用户在未检出时更换图片，并明确提示远景、旋转和边缘裁切风险；
- 不通过反复修改阈值来迎合这一小型合成集合；
- 保留 SCRFD 适配边界和模型切换能力，用于后续对比，而不混用其研究权重许可证；
- 完成逐图授权的本地真实图片基准后，再决定是否调整默认检测器或配置。
