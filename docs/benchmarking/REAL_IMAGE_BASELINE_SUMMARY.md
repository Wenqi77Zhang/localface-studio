# 本地真实图片人脸检测基准冻结摘要

状态：`real20-v1` 已冻结
冻结日期：2026-08-21

## 摘要

本项目已完成 20 张真实图片、30 张人工复核人脸的本地检测冒烟基准。所有图片均经过逐图来源、许可证、内容安全、方向和人脸框复核；原图、逐图台账、人工框和逐图报告仅保存在被 Git 忽略的本地工作区。

本摘要只公开脱敏合计指标，不能用于身份识别、人口属性推断、真实世界准确率宣传、公平性结论或商业可靠性证明。

## 数据边界

- 候选入口为 Open Images V7 官方元数据；数据集声明不能替代逐图许可证核验。
- 接受图片的原始落地页均在审核时明确显示 CC BY 2.0。
- 内容门禁要求可辨识人物明确为成年人，并排除私人空间、医疗、暴力、政治、性意味及其他可能增加当事人风险的场景。
- 不保存单独的人脸裁剪，不记录人物姓名，不执行身份识别或人口属性推断。
- 公开仓库不包含真实原图、缩略图、逐图来源、人工框、逐图报告或本机路径。

## 冻结结论

YuNet 继续作为零付费、CPU 优先、许可证边界较清晰的**临时默认检测器**。本轮未观察到误检，但 60% 的总体召回率以及大脸贴边、裁切、侧脸和帽檐场景的集中漏检，不能支持“已具备普遍可靠性”的结论。

阶段 3 的模型选择结论如下：

1. 产品必须继续在无脸或漏检时给出明确提示，不得静默选择或静默切换模型。
2. 不为迎合这 20 张图片而单独调低阈值。
3. `scrfd-insightface-research` 在本集召回率更高，但许可证受限且出现 2 个未匹配检测，因此只保留为明确确认后的本地研究选项。
4. YuNet 继续作为公开默认检测器；“默认”表示许可证与分发边界更适合公开项目，不表示准确率普遍优于 SCRFD。
5. 未来商业使用只能采用许可证允许的 YuNet 或完成训练数据、权重来源和再分发审计的 `scrfd-custom`。

## 变更控制

`real20-v1` 冻结后，不得静默替换图片、人工框、方向处理或评测参数。若发现许可证撤回、来源冲突、标注错误或安全问题，应：

1. 记录触发原因；
2. 从本地冻结集移除受影响样本；
3. 按同一准入流程补充替代样本；
4. 使用新的冻结标识重新运行所有检测器；
5. 在公开摘要中说明版本变化，不能覆盖旧结果后假装未发生变更。
