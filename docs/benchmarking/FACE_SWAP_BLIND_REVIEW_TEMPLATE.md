# LocalFace Studio 换脸盲评模板

评审者只查看随机化的 A/B 结果，不显示预设名称、模型名称或自动分数。每项使用 1–5 分；无法判断时填写 `NA`，不得强迫评分。

## 评审规则

- 身份项只比较来源人物与换脸结果，不用“更好看”替代身份判断。
- 姿态和表情项只比较目标图与结果。
- 多人图必须单独检查未选人物是否变化。
- “明显伪影”包括双眼、牙齿、发际线、轮廓、遮挡关系和肤色断层问题。
- 至少两位互不沟通的评审者完成后再揭盲；报告评审人数、分歧和 `NA` 数量。
- 小样本盲评只用于发现回归，不构成人群公平性、真实世界可靠性或商业质量证明。
