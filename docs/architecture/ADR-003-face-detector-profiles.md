# ADR-003：可替换的人脸检测器与许可证隔离

状态：已接受  
日期：2026-07-24

## 背景

阶段 3 需要处理来源图歧义、目标图多脸检测、稳定编号和目标人物选择。项目同时需要：

- 使用许可证清晰、适合未来公开发行的默认检测器。
- 允许个人学习阶段对比更高精度的研究模型。
- 为未来使用自有合规数据训练 SCRFD 预留替换路径。
- 避免受限权重进入 GitHub、安装包或未来商业运行模式。

YuNet 与 SCRFD 都是人脸检测器。它们主要影响人脸是否被检出、边界框、关键点和后续对齐，不直接替代 `FaceSwapper` 的身份替换能力。

## 决策

实现统一 `FaceDetector` 契约，并登记三个稳定的检测器配置：

| 检测器 ID | 用户界面名称 | 用途 | 默认状态 |
|---|---|---|---|
| `yunet-opencv` | YuNet（推荐｜可公开使用） | 默认检测和公开发行 | 可选且默认 |
| `scrfd-insightface-research` | SCRFD（实验｜仅限非商业研究） | 本地研究对比 | 未安装时禁用 |
| `scrfd-custom` | 自训练 SCRFD | 未来自行训练或取得合规授权后的替换路径 | 预留，不显示为可用 |

统一输出至少包含：

- 任务内稳定检测 ID。
- 边界框。
- 五个人脸关键点。
- 检测置信度。
- 检测器 ID、适配器版本、权重版本和权重 SHA-256。

## 切换和一致性规则

1. 检测器在高级设置中选择，默认值始终是 `yunet-opencv`。
2. 切换检测器会使当前检测框、稳定编号、来源人脸选择和目标人脸选择全部失效。
3. 切换后必须重新检测；不得把一个检测器产生的检测 ID 传给另一个检测器。
4. 后端保存任务使用的检测器 ID、版本、哈希、阈值和输入尺寸，导出元数据不得包含本机绝对路径。
5. 模型未安装、哈希不匹配或许可证门禁未通过时，后端拒绝启动检测，不得静默回退。
6. 对比实验必须固定输入图片和其他参数，并分别记录检测成功率、漏检、误检、关键点稳定性和下游结果。

## 许可证隔离

- OpenCV Zoo 的 YuNet 模型目录采用 MIT 许可证，可作为默认候选；OpenCV 运行时代码许可证单独登记。
- InsightFace 源代码采用 MIT，但其官方预训练模型仅限非商业研究。
- `scrfd-insightface-research` 不进入 Git、发布包或默认安装流程；首次启用前必须明确展示限制并取得确认。
- 商业运行模式必须由后端禁止加载 `scrfd-insightface-research`，不能只依赖前端隐藏或提示。
- `scrfd-custom` 只有在训练数据权利、训练过程、权重来源和分发许可完成登记后才能标记为商业兼容。

## 自训练 SCRFD 的预留资产

未来的 `scrfd-custom` 模型清单必须包含：

- 模型卡和用途限制。
- 训练数据来源、授权范围及排除记录。
- 训练代码版本、配置、随机种子和环境快照。
- 验证数据及小脸、遮挡、旋转、多脸指标。
- 权重文件名、格式、大小和 SHA-256。
- 与研究权重不存在混用或继续训练关系的证明。
- 商业使用与再分发结论及人工复核记录。

## 后果

- 可以在不修改业务流程的情况下比较 YuNet、研究版 SCRFD 和未来自训练 SCRFD。
- 任务和结果能够追溯到具体检测器，实验更可复现。
- 受限模型会增加首次启用确认、模型清单和测试分支。
- 检测器切换必须重置选择状态，前端不能保留旧检测框。

## 重新评审条件

- 默认检测器未达到阶段 3 验收标准。
- InsightFace 官方模型许可证发生变化。
- 项目准备商业部署或公开提供模型下载。
- 自训练 SCRFD 准备进入默认或公开发行路径。
