# ADR-005：可替换真实处理器与双结果工件

日期：2026-09-11（测试数据采集于 09-10 UTC）
状态：按本轮“直接优化、去除伪实现”的授权落地；不改变本地/非商业范围。

## 决策

工作流只组织阶段，`FaceSwapper` 返回真实 BGR 图像与实际执行器；`FaceEnhancer` 接收原目标和基础结果，返回同尺寸图像。InSwapper/AlphaFace 共用 ArcFace 来源编码，逐任务明确选择模型。切换时释放旧推理会话，不长期同时占用两套 GPU 模型。

| 结果方式 | 工件 | 默认下载 |
| --- | --- | --- |
| identity | base | 基础版 |
| balanced | base + enhanced | 色彩优化版 |
| 显式 simulation/可选 ComfyUI | legacy final | 按实际后端披露 |

不改写既有 SQLite 记录。新 `variant` 查询参数映射固定枚举，默认 `final` 是兼容别名，按 enhanced、base、旧 result 文件顺序解析，不接受客户端文件路径。

## 生命周期与安全

- 基础结果经过真实推理、尺寸/数据类型/非空变化校验后写入。完全未变化或不合法输出直接失败。
- 色彩优化读取临时无损、无水印基础像素，避免重复 JPEG 压缩和双重水印；只处理局部区域，不修改基础工件。
- 各版本独立写入 AI 编辑、模型、执行器、水印和版本元数据；只有整个任务成功才可下载。
- 成功后移除输入和中间文件；失败、取消、超时沿用队列全工作区清理。删除覆盖全部版本和指标文件。
- 结果/缩略图/清单接口均校验当前会话和到期时间；到期浏览器 Blob 链接也撤销。
- 删除文件成功后才提交 deleted/expired 状态。文件被占用时返回可重试状态，不能虚报已清除。

## 性能与可观察性

图库使用最多 480×320 的缩略图，不批量加载原尺寸结果。事件历史最多缓存 256 个任务、每任务 64 条；资源报告只含数值，不记录人脸向量、图片、硬件编号或本机路径。

RSS 是进程驻留内存采样，VRAM 是整台设备上显存使用量采样，不是精确的单进程 CUDA 分配峰值。不存在 GPU 读数时用 null。采样线程和外部查询均有边界，不能把无指标当作零占用。

## 不做的事

不把颜色调整称作超分辨率/生成式修复，不将 MIT 代码许可扩张到模型权重，不自动选择新模型替代默认基线。不实现账号、视频或公网部署；这些仍需各自的许可和验收链。
