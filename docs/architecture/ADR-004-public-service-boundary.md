# ADR-004：本地研究产品与公网服务使用独立安全边界

状态：已接受  
日期：2026-08-27

## 决策

当前应用继续只接受明确配置的回环地址和前端端口。未来公网版本不得复用“删除回环校验”这一方式上线，而应建立独立部署配置、账户与授权层、数据隔离层、滥用治理层和已获许可的模型后端。

## 原因

本地单用户假设允许使用匿名浏览器会话、项目内 SQLite 和短期本地文件。公网环境存在不可信用户、跨租户访问、自动化滥用、内容政策、密钥管理、可用性和法律责任，这些风险不能由 CORS 或一个登录页面单独解决。

## 后果

- 当前零付费本地版不会被误配置为公网人脸处理服务。
- 公网研发可以复用任务领域模型和后端接口，但必须重新实现身份、存储、策略和部署边界。
- 在生产门禁完成前，只能发布源码、文档和明确标注为“本地运行”的产品介绍，不能宣称在线换脸已上线。
