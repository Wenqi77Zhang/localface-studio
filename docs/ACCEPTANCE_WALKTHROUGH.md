# LocalFace Studio 候选版使用与验收演练

适用版本：`1.0.0rc2`  
预计用时：30–45 分钟  
目标：让非开发人员用可观察结果判断“能否使用”，而不是只看测试通过。

## 0. 素材与隐私准备

准备三组已获得明确授权的成年人图片，其中至少一张目标图包含两张以上清晰人脸。不要使用未成年人、证件照、医疗或私密场景，也不要把图片、结果或诊断以外的运行目录提交到 GitHub。

每组尽量包含：清晰正脸、轻微侧脸、光照或角度有差异的目标图。验收结果可能暴露人物身份，只保存在本机。

## 1. 启动前检查

1. 关闭以前打开的 LocalFace Studio 启动窗口。
2. 双击 `diagnose.cmd`。
3. 确认 Python、Node、模型、ONNX Runtime 和显卡均为 `OK`。
4. 如果端口 8000 或 5173 为 `WARN`，关闭旧启动窗口后再诊断；不要盲目结束不认识的系统进程。
5. 首次安装或换电脑时，先双击 `setup.cmd`，再双击 `verify-install.cmd`。

通过标准：没有 `FAIL`；诊断报告不含图片、用户名、主机名或本机绝对路径。

## 2. 启动并辨认真后端

1. 双击 `start.cmd`。
2. 等待浏览器打开 `http://127.0.0.1:5173/`。
3. 查看页面顶部运行状态。真实质量验收必须明确显示本地真实后端和模型已就绪；若显示模拟模式，只能验收页面交互，不能评价换脸效果。

通过标准：页面可打开、无“来源不允许”、模型缺失或持续离线提示。

## 3. 单脸主流程

1. 上传一张单人身份来源图和一张单人目标场景图。
2. 确认检测框覆盖正确的人脸。
3. 勾选影像授权和非商业研究模型限制。
4. 保持 YuNet、平衡优化、PNG、30 分钟和默认 AI 水印。
5. 点击“开始本地换脸”，等待任务完成。
6. 拖动前后对比线，并用“放大质检”查看完整图片。
7. 下载结果，确认尺寸与目标图一致、右下角有 AI 水印。

逐张检查眼睛、牙齿、发际线、耳朵、脸部轮廓、肤色衔接、背景和身体。明显重影、破脸或替换错人即记为失败，不得用自动指标覆盖人工结论。

## 4. 多脸单目标

1. 保留来源图，换成包含两张以上人脸的目标图。
2. 逐个点击人物编号，确认高亮框与编号一致。
3. 只选择其中一人并运行。
4. 对照原图确认只替换所选人物，其他人物和背景没有不可解释变化。

通过标准：检测 ID、界面选择和实际被替换人物一致；不能同时选择两人。

## 5. 缺项与失败路径

分别尝试：不上传图片、只上传一张、未选择目标人物、未勾选授权。按钮可以点击，但不得启动任务；页面必须明确指出缺少的项目。再尝试一张无法检测清晰人脸的图片，程序必须显示可理解错误且不生成伪结果。

任务运行时点击取消。状态最终必须成为已取消或已停止，且不能留下可下载的半成品。

## 6. 高级设置与导出

1. 展开高级设置，比较 YuNet 与仅限研究的 SCRFD 检测结果；记录各自检测数量，不以单张图推断普遍优劣。
2. 分别运行“身份优先”和“平衡优化”。当前实现每次只保存所选预设的一个结果，不是基础/增强双结果。
3. 选择 JPEG，将质量滑杆调到 5、95 和 100；用方向键、Home、End 检查键盘操作。
4. 关闭可见水印，确认出现二次警告；导出后文件仍必须保留 AI 编辑元数据。
5. 检查 PNG 和 JPEG 均能下载并由常见图片查看器打开。

## 7. 图库、保留与删除

1. 确认新结果出现在左侧图库，排序从新到旧。
2. 点击缩略图，确认大图完整缩放、无滚动截断，并可下载。
3. 点击“清除此结果”，确认出现二次确认并只删除应用工作区副本。
4. 检查 Windows 已下载文件仍存在；应用删除不应越权删除下载目录。
5. 可用一小时保留期检查设置契约；无需为了验收等待自然过期，自动清理行为由测试门覆盖。

## 8. 结束与记录

回到启动窗口按 `Ctrl+C`，等待前后端一同退出；只关浏览器标签页不算停止。再次运行 `diagnose.cmd` 时端口不应继续报警。

在[最终集中验收清单](FINAL_ACCEPTANCE.md)逐项勾选，并为三组真实图片记录：检测器、质量预设、是否换对人、是否出现明显伪影、接受或拒绝。公开仓库只写匿名聚合结论，不上传人物图、生成结果或本机路径。

## 9. 当前发布判断

- 本地个人学习与已授权成年人素材演示：可以继续验收。
- 稳定 `v1.0.0`：尚不可发布，仍缺双工件增强链、独立换脸/增强接口、资源稳定性曲线、集中视觉验收和干净 Windows 复现。
- 公网或商业服务：禁止直接部署，必须先替换或取得模型商业许可，并完成账户隔离、滥用治理、基础设施和法律审查。
- 视频换脸：只有接口预留，尚无可使用功能。
