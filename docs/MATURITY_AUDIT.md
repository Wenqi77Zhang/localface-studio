# LocalFace Studio 成熟度审计

审计日期：2026-08-27
审计对象：`1.0.0rc2` 本地单用户研究候选版

## 结论

本地产品闭环、隐私边界、失败恢复、自动清理、模型可替换接口、Windows 交付和公开仓库治理已达到候选产品水平。当前可以用于个人学习、授权成年人素材的本地演示和代码审查，但不能称为公开生产服务，也不能使用当前研究权重开展商业活动。

## 已通过的成熟度门

- 输入内容探测、像素与文件上限、多帧拒绝、授权和研究许可证双门禁。
- 多脸检测、稳定检测 ID、单目标选择、任务并发上限、取消、超时和重启恢复。
- 成功后立即删除来源图与目标图，只保留最终结果；保留期硬上限 24 小时。
- 匿名本地会话可跨后端重启恢复，Cookie 原值不落盘，会话过期自动拒绝。
- 处理能力明确区分真实可用、仅模拟、尚待配置、CPU 降级和首次加载。
- Host、Origin、Fetch Metadata、CSRF、安全响应头和精确回环端口白名单。
- 锁定依赖、80% 覆盖率门、公开仓库扫描、Git 历史扫描、Windows CI、Dependabot 和 CodeQL。
- 2026-08-27 本地审计中 npm 生产依赖与 Python 当前锁定环境均未发现已知漏洞。

## 未通过或必须人工完成的门

- 真实 7 例基线仍有 2 例明显重影或融合伪影，必须逐张人工放大检查。
- 独立干净 Windows 物理机复现和产品负责人集中视觉验收尚未完成。
- 当前 ArcFace、InSwapper 和可选 SCRFD 权重不是公开商业服务许可证。
- 视频、账户、跨用户数据隔离、滥用举报、内容治理和公网基础设施尚未实现。

## 发布判断

允许继续发布 `1.0.0rc2` 源码和本地研究演示；不允许创建稳定 `v1.0.0` 标签，不允许将处理 API 绑定公网地址，也不允许把静态产品介绍页表述为已部署的在线换脸服务。
