# LocalFace Studio 成熟度审计

审计日期：2026-09-03
审计对象：`1.0.0rc2` 本地单用户研究候选版

## 结论

主要本地产品闭环、隐私边界、失败恢复、自动清理、Windows 交付和公开仓库治理已达到候选产品水平。当前可以用于个人学习、授权成年人素材的本地演示和代码审查，但尚未满足全部冻结需求，不能称为稳定版或公开生产服务，也不能使用当前研究权重开展商业活动。

## 2026-09-03 超级审查证据

- 完整质量门再次通过：Ruff、格式、严格 Mypy、144 项 Pytest、82.57% 覆盖率、公开仓库与 Git 历史扫描、后端冒烟、前端检查、生产构建及前后端代理联调。
- 当前锁定 Python 环境与全部前端依赖的漏洞审计均未发现已知漏洞；本地项目包因不在 PyPI 而被审计工具正常跳过。
- 使用真实 Microsoft Edge 完成上传、三脸检测、单目标选择、缺项提示、授权门禁、任务成功、节点重置、高级设置、JPEG 键盘调节、水印二次确认、结果下载、图库大图和二次确认清除。
- 浏览器控制台原有的站点图标 404 已修复，并加入生产联调验证；复验为 0 个错误、0 个警告。
- 下载结果的模拟声明、AI 编辑标记、水印状态、后端、质量预设和 JPEG 质量元数据均可读取。模拟结果只证明产品流程，不作为真实换脸质量证据。
- 本机隐私安全诊断确认 YuNet、SCRFD、InSwapper、ArcFace 文件大小有效，CUDA 与 CPU 执行器可用；默认端口当时已有进程监听，因此保留为需人工关闭旧实例的警告。

## 已通过的成熟度门

- 输入内容探测、像素与文件上限、多帧拒绝、授权和研究许可证双门禁。
- 多脸检测、稳定检测 ID、单目标选择、任务并发上限、取消、超时和重启恢复。
- 成功后立即删除来源图与目标图，只保留最终结果；保留期硬上限 24 小时。
- 匿名本地会话可跨后端重启恢复，Cookie 原值不落盘，会话过期自动拒绝。
- 处理能力明确区分真实可用、仅模拟、尚待配置、CPU 降级和首次加载。
- Host、Origin、Fetch Metadata、CSRF、安全响应头和精确回环端口白名单。
- 锁定依赖、80% 覆盖率门、公开仓库扫描、Git 历史扫描、Windows CI、Dependabot 和 CodeQL。
- 2026-08-27 本地审计中 npm 生产依赖与 Python 当前锁定环境均未发现已知漏洞。
- 结果区提供可键盘操作的前后对比、完整大图质检、新窗口原图查看和焦点受限弹窗；高风险几何条件只做透明预警，不冒充审美评分。
- 前端构建工具更新后保持零检查警告；文件预览、检测请求、任务结果与图库弹窗状态的生命周期已重新收敛并通过 Edge 视觉回归。

## 未通过或必须人工完成的门

- 真实 7 例基线仍有 2 例明显重影或融合伪影；现已补齐人工放大质检闭环，但模型质量上限本身尚未解决。
- 冻结需求要求基础换脸结果与可选增强结果独立保存和配对比较；当前 `identity` / `balanced` 是单次任务的二选一预设，只生成一个结果，不能视为已满足。
- ADR-001 冻结的独立 `FaceSwapper` 与 `FaceEnhancer` 可测试边界尚未实现；真实换脸目前封装在原生工作流后端中。`FaceDetector` 与 `WorkflowBackend` 已具备协议边界。
- 性能基线已有冷启动、热任务和输出尺寸，但尚缺峰值显存、进程内存以及足够长的连续任务泄漏曲线。
- 独立干净 Windows 物理机复现和产品负责人集中视觉验收尚未完成。
- 当前 ArcFace、InSwapper 和可选 SCRFD 权重不是公开商业服务许可证。
- 视频、账户、跨用户数据隔离、滥用举报、内容治理和公网基础设施尚未实现。

## 发布判断

允许继续发布 `1.0.0rc2` 源码和本地研究演示；不允许创建稳定 `v1.0.0` 标签，不允许将处理 API 绑定公网地址，也不允许把静态产品介绍页表述为已部署的在线换脸服务。稳定版至少还需完成双工件增强契约、独立换脸/增强接口、资源稳定性实测、真实图集中验收和干净 Windows 复现。
