## 新增的纵深防御

- 所有 API 响应携带 `no-store`、`nosniff`、拒绝 iframe 嵌入、无引用来源、禁用摄像头/麦克风/定位和同源资源策略。
- PNG 文本与 JPEG EXIF 只接受固定的隐私安全元数据字段；新增未知字段或缺失强制披露会直接使导出失败。
- 后端成功发布结果后立即删除两张上传原图；若删除失败，任务不会保留“成功”状态，而会进入失败清理。
- 浏览器关闭可见水印前显示后果说明，并明确元数据仍会保留。
