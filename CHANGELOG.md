# Changelog

All notable project changes are recorded here. The project follows semantic versioning after the first approved stable release.

## Unreleased — v1.0.0 release candidate

- Completed the local single-image face-swap product flow with multi-face detection and one selected target.
- Added YuNet and gated SCRFD detection profiles, plus a GPU-first native ArcFace/InSwapper research backend.
- Added auditable identity and balanced quality presets with an honest seven-case quality baseline.
- Added PNG/JPEG export, permanent AI metadata, default visible watermark, local result retention and deletion.
- Minimized successful task storage to the result only and completed the phase 7 security acceptance matrix.
- Added an isolated, loopback-only optional ComfyUI adapter without bundled nodes, models or workflows.
- Added Windows setup, startup, diagnostics, user documentation and public repository quality gates.
- Reserved versioned video frame, tracking, temporal consistency, audio mux and checkpoint interfaces without claiming video support.

The stable `v1.0.0` tag remains blocked on final product-owner visual acceptance and independent clean-Windows reproduction.
