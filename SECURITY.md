# Security Policy

## Supported version

Until `v1.0.0` is approved, only the current `main` release candidate receives security fixes.

## Private reporting

Use [GitHub private vulnerability reporting](https://github.com/Wenqi77Zhang/localface-studio/security/advisories/new). Do not open a public issue for a vulnerability.

Never attach face photos, generated results, model files, identity vectors, credentials, complete runtime databases, absolute user paths or unredacted logs. Reproduce with synthetic non-personal data and include only the smallest redacted technical detail needed.

## Scope

The current security boundary is a single-user, loopback-only Windows research application. Public, LAN, cloud, multi-user and commercial deployments are unsupported and have not received the required authentication, abuse-prevention, legal or penetration testing.
