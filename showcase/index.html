01 / THE WORKFLOW

不是一次点击。
是每一步都有交代。

当前本地应用的真实处理链。
选择步骤，了解每一步做什么、为什么做。

INPUT & CONSENT01

处理前，把边界说清楚。

来源图提供需要保留的身份特征；目标图提供姿态与场景。校验不只看扩展名，还检查文件内容、尺寸、像素和帧数。

  • 支持 PNG、JPEG、静态 WebP 输入
  • 要求确认图片与人物肖像的合法授权
  • 研究权重另有用途确认，不混同于图片授权
  • 缺少输入时明确提示，不伪装成处理成功
这些能力运行于本地应用。本展示页没有上传入口。
DETECT & SELECT02

多张人脸，一个明确目标。

检测框与编号帮助定位人物；选择会由后端再次核验，而不只在界面上画一个框。横图、竖图都完整显示，空白区域留黑。

  • YuNet 为默认检测器，SCRFD 为研究对照
  • 来源与目标均可显式选择人物
  • 一项任务只替换一个目标人物
  • 检测成功不等于换脸完成，两个状态分别反馈
换用 YuNet 并不会解除身份编码与换脸权重的用途限制。
NATIVE INFERENCE03

真正执行，而不是展示进度动画。

Python 与 ONNX Runtime 在本机执行模型。InSwapper 128 是当前默认，AlphaFace 256 可作为对照；新模型不自动等于更好的身份保真。

  • GPU 推理与明确标识的 CPU 降级
  • 节点状态、取消、超时和重启恢复
  • 模型缺失或执行失败时不会生成假结果
  • 原生路径独立运行，不要求先安装 ComfyUI
模拟后端仅用于显式开发与测试，不作为真实模型质量证据。
COMPARE, THEN CHOOSE04

让“更好”成为可比较的选择。

保留基础结果，同时可生成局部色彩优化版本。两份结果是独立文件，优化不会覆盖基础版，也不承诺每张图片都更相似。

  • 基础 / 色彩优化结果配对展示与下载
  • 支持键盘操作的前后对比与完整大图
  • 色彩校正不是生成式五官修复或超分辨率
  • 复杂眼妆、遮挡与大角度仍可能产生伪影
最终质量需要逐图观察；执行成功率不等于审美通过率。
EXPORT & RETENTION05

导出有标识，保留有期限。

结果支持 PNG 或 JPEG；JPEG 质量在 5–100 之间调整，默认 95。结果图库只展示当前会话的可用结果，可单独下载或清除。

  • 导出时写入 AI 编辑元数据
  • 可见水印默认开启，关闭需再次确认
  • 成功后清理输入，结果保留最长 24 小时
  • 清除应用结果不会删除另行下载的副本
外部软件可能移除元数据。文件权限异常会触发清理重试，物理删除仍需核实。

公网部署门禁 ↗（在新标签页打开）
这里可以上传照片，直接体验吗？+

不能。本页是独立静态介绍站，没有上传、注册、推理或下载个人结果的入口，也不会连接浏览者或开发者的本地换脸服务。实际使用需要按 GitHub 指南在本机安装应用和合适用途的模型。

为什么没有公开真人换脸对比图？+

素材获准用于本地研究，不代表人物肖像和处理结果已获准在公网展示。此版本仅发布脱敏汇总和明确标记的逻辑示意，不公开研究照片、结果、人脸向量或模型权重。真实结果展示需要另行核验展示授权与用途。

开源代码，是否就能直接商用？+

不能据此推断。应用代码、模型代码、预训练权重和训练数据有各自的许可。当前研究执行链包含用途受限的模型；免费或受邀试用也不自动取得服务许可。

请分别核验InsightFace 官方说明 ↗（在新标签页打开）、当前 AlphaFace 转换权重登记 ↗（在新标签页打开）和项目许可清单 ↗（在新标签页打开）。这些工程边界说明不代替针对具体用途的法律意见。

数据留在本地，具体指什么？+

本地应用的处理服务仅监听回环地址，图片与推理在使用者电脑上处理，不依赖付费云端推理接口。本展示页代码不含图片采集、访客分析脚本或表单提交；托管平台仍可能按其规则记录常规访问日志。

结果保留期限不超过 24 小时；权限异常时清理会重试，不能把“禁止访问”误认为“文件已删除”。下载到其他位置的副本由使用者自行管理。

视频处理和 ComfyUI 到什么阶段了？+

视频扩展接口已经规划，但视频处理尚未实现。应用目前使用独立原生后端完成单张照片处理；ComfyUI 作为可选适配方向，未附带可直接使用的换脸工作流。
